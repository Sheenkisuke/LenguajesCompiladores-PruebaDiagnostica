## 📌 Descripción del Proyecto

Este repositorio contiene la solución a los 3 problemas de la prueba diagnóstica de la materia Lenguajes y Compiladores. Cada problema ha sido implementado en C++ y se encuentra en su respectiva carpeta con su código fuente, script de instalación y documentación.

---


## 📋 Resumen de los Problemas

| Problema | Título | ¿Qué hace? |
|----------|--------|-------------|
| 1        | Clasificación de Expresiones Aritméticas | Clasifica componentes de una expresión aritmética (números, operadores, paréntesis, operandos, errores) y verifica balanceo de paréntesis |
| 2 | Validador FEN | Valida si una cadena cumple con la notación FEN (Forsyth-Edwards Notation) del ajedrez |
| 3 | Conjetura de Collatz | Verifica la conjetura de Collatz para todos los números en un intervalo [p, q] bajo la condición q ≥ 100p |

## 🔧 Requisitos Previos

Para compilar y ejecutar los programas necesitas:

- Code::Blocks 20.03 (recomendado)  
  Descargar desde: http://www.codeblocks.org/

- Opcional: Compilador MinGW (g++) en el PATH

---

## 🚀 Cómo Compilar y Ejecutar

### Opción 1: Code::Blocks (Recomendado)
1. Abrir Code::Blocks
2. Abrir el proyecto `.cbp` de cada problema
3. Presionar `F9` (Compilar y ejecutar)

### Opción 2: Línea de comandos con MinGW

#### Problema 1
cd Problema1
g++ main.cpp -o main.exe
./main.exe

#### Problema 2
cd Problema2
g++ main.cpp -o main.exe
./main.exe

#### Problema 3
cd Problema3
g++ main.cpp -o main.exe
./main.exe


Opción 3: Usar setup.bat
Hacer doble clic en setup.bat dentro de cada carpeta para ver instrucciones.
